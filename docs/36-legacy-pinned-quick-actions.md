# 2026-10-30｜主選單置頂快捷功能：手機/平板/桌機本地自訂

原版：`yukidu/Echo-Starry/src/components/Navbar.tsx` + `src/quickShortcutPreferences.ts`，會員可自行選擇置頂快捷、排序，裝置類型上限分別為 mobile=3、tablet=5、desktop=不限；原版涉及部分私人會員/貼紙/通知/管理頁，**不能未經授權直接接通**。

本批 PR 完成**能真實運作**的 RN Web/Expo 本機快捷列設定：
- 新增安全可用的7個動作：首頁、好心情、講師作品、排行榜、我的收藏、會員入口、深/淺色模式；都只是已有 Expo 公開路由或本機主題操作，**絕不額外授權私人資料**。
- 主選單「置頂快捷功能」可勾選/取消、以 ↑↓ 操作重新排序，變更即時反映頂部快捷列；當全部取消時顯示「設定快捷功能」入口，不會讓使用者失去回復途徑；所有觸控目標至少44px、勾選狀態及 disabled 具 a11y 資訊。
- 手機限制3個、平板5個、桌面最多目前可用的7個；各類裝置**分別儲存**，避免手機窄螢幕被桌機的多功能排滿。切換 viewport 即使用對應設定。儲存使用獨立 AsyncStorage UI key，無會員 API，跨頁不丟失、讀取失敗不覆蓋未知舊資料、寫入順序受保護。
- 有本機喜好色彩與 A−/A＋ 持久化的原功能維持；快捷列不顯示尚未授權的「通知、貼紙、音檔管理、後台」可用動作，也不假設中央會員已登入。
- `tests/legacy-pinned-quick-actions.test.mjs` 逐項測試預設手機/平板/桌面上限、資料清洗、持久化、移動順序、所有快捷取消後恢復、讀取失敗、實際導覽 wiring。

**尚未達到真正完全 1:1 的細節：** 這一批先使用易操作且具鍵盤/無障礙支援的 ↑↓ 調整順序；**原版的按住拖曳手勢尚未實作／真機驗收**，亦尚未將會員雲端快捷偏好同步。需要另批修復，不能稱所有舊版快捷體驗已完成。任何需真正登入的權限功能仍取決於 Starry ID/業務 API 和權利 Gate。

合併後由既有 GitHub 受保護 main CI 綠燈 → Production 自動發布 Web shell，公開28 guest封面與私人stream 404安全驗收必須成功。所有精確SHA/CI/Production 紀錄寫到 Issue #3。
